# Heteroscedastic Neural Regression Benchmark

Code and result data accompanying the manuscript:

**Heteroscedastic Neural Regression with Monte Carlo Dropout: Data-Resampled, Group-Aware, and Distribution-Shift Benchmarking**

Public repository folder: https://github.com/Researchteamforus/ChatGpt/tree/main/heteroscedastic-uq-regression

## Contents

- `analysis/reviewer10_final_analysis.py` — complete analysis workflow, including synthetic/OOD experiments, repeated-data sensitivity, real-data benchmarks, conformal comparators, hyperparameter sensitivity, and posterior-draw sensitivity.
- `analysis/compute_benchmark.py` — CPU training and inference benchmark.
- `results/` — seed-level, fold-level, outer-realization, bootstrap, OOF-prediction, sensitivity, compute, and environment outputs.
- `tests/test_reviewer10_analysis.py` — implementation tests for clipping gradients, exact mixture NLL, Protocol B dataset reuse, conformal quantiles, and posterior predictive draws.
- `REPRODUCIBILITY_CHECKLIST.md` — execution and reporting checklist.
- `REVIEWER_ISSUE_RESOLUTION_MATRIX.md` — audit trail for the ten reviewer-role critiques.

## Reproduction

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python analysis/reviewer10_final_analysis.py
python analysis/compute_benchmark.py
pytest -q tests
```

The workflow is CPU-compatible. Runtime depends on hardware. The environment used for the supplied outputs is recorded in `results/software_hardware_environment.json`.

## Methodological safeguards

- Gaussian-NLL training and evaluation use the same log-variance clamp: `[-6, 6]`.
- PyTorch's clamp derivative is zero outside the bounds.
- MC Dropout and Deep Ensemble NLL use exact finite Gaussian-mixture densities.
- Protocol B generates one dataset per outer realization and reuses that dataset across inner optimization seeds.
- Fixed-data optimization seeds are treated descriptively rather than as independent population replications.
- California Housing was excluded from the final evidentiary core because a valid censored-target sensitivity rerun was not available from the locked archive.

## Data provenance

No confidential or participant-level clinical data are included. Synthetic and simulated datasets are generated by the analysis script. Public benchmark datasets are loaded through `scikit-learn` and `statsmodels`. The repository provides processed result tables and out-of-fold predictions required to audit the reported analyses.
