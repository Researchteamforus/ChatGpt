# Heteroscedastic Neural Regression Benchmark

Code and processed result data accompanying the manuscript:

**Heteroscedastic Neural Regression with Monte Carlo Dropout: Data-Resampled, Group-Aware, and Distribution-Shift Benchmarking**

## Contents

- `analysis/main_analysis.py.gz` — exact compressed analysis workflow. Extract it with `gzip -dk analysis/main_analysis.py.gz`.
- `analysis/compute_benchmark.py` — CPU training and inference benchmark.
- `results/` — publication-facing benchmark summaries, seed-level OOD utility data, compute results, software/hardware metadata, and the test log. Running the analysis script regenerates the complete result set.
- `tests/test_analysis.py` — implementation tests for clipping gradients, exact mixture NLL, Protocol B dataset reuse, conformal quantiles, and posterior predictive draws.
- `REPRODUCIBILITY_CHECKLIST.md` — execution and reporting checklist.

## Reproduction

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
gzip -dk analysis/main_analysis.py.gz
python analysis/main_analysis.py
python analysis/compute_benchmark.py
pytest -q tests
```

The workflow is CPU-compatible. Runtime depends on hardware. The environment used for the supplied outputs is recorded in `results/software_hardware_environment.json`.

## Methodological safeguards

- Gaussian-NLL training and evaluation use the same log-variance clamp: `[-6, 6]`.
- PyTorch's clamp derivative is zero outside the bounds.
- MC Dropout and Deep Ensemble NLL use exact finite Gaussian-mixture densities.
- Protocol B generates one dataset per outer realization and reuses that dataset across inner optimization seeds.
- Fixed-data optimization seeds are treated descriptively rather than as independent population replications.
- California Housing was excluded from the final evidentiary core because a valid censored-target sensitivity rerun was not available from the locked archive.

## Data provenance

No confidential or participant-level clinical data are included. Synthetic and simulated datasets are generated by the analysis script. Public benchmark datasets are loaded through `scikit-learn` and `statsmodels`. The committed CSV files are processed analysis outputs; the script regenerates the full seed-, fold-, bootstrap-, and prediction-level result files.
