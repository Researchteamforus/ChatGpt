# Ten-Reviewer Issue Resolution Matrix

This matrix records how the ten independent reviewer-role critiques were addressed in the final verified revision. Numerical claims are traceable to CSV files in `results/`; implementation claims are covered by the source code and passing tests in `tests/`.

| Reviewer lens | Principal concern | Resolution in the final revision | Auditable evidence |
|---|---|---|---|
| 1. UQ methodology | Gaussian-NLL was described too broadly despite failures on some real/shift settings. | Removed universal-superiority language; the conclusion now states that deterministic heteroscedastic NLL improves some benchmarks but is unstable under small-data, temporal, and cross-firm shift. MC Dropout is characterized as configuration-sensitive. | `results/*_oof_summary.csv`, `results/grunfeld_temporal_summary.csv`; Discussion Sections 4.1 and 4.6. |
| 2. Experimental design | Limited breadth, optimistic row-wise panel splits, and too few outer replications. | Added Diabetes, Engel, leave-one-firm-out Grunfeld, four disjoint temporal test windows, a multivariate covariate-tail shift, and ten independent synthetic outer realizations with two inner seeds. California top-coded results were removed from the evidentiary core instead of being defended without a censored-likelihood rerun. | `results/diabetes_oof_summary.csv`, `engel_oof_summary.csv`, `grunfeld_group_oof_summary.csv`, `grunfeld_temporal_*`, `protocol_b_*`. |
| 3. Statistical inference | Optimization seeds were treated as paired independent inferential units; overlapping splits made p-values over-confirmatory. | Removed confirmatory seed-level p-values. Fixed-data seeds are descriptive. Real-data contrasts use paired prediction-level bootstrap intervals; Grunfeld uses firm-cluster bootstrap. All intervals are explicitly conditional/descriptive rather than population-level proof. | `results/*_bootstrap_contrasts.csv`; Methods Section 2.6. |
| 4. OOD/shift evaluation | One-dimensional OOD variance increases did not demonstrate usefulness. | Added region-specific MSE/NLL/PICP/MPIW/R-ECE, OOD AUROC/AUPRC, uncertainty-error correlation, selective-risk curves, Diabetes multivariate support-tail shift, and Grunfeld temporal/group shift. | `synthetic_region_*`, `synthetic_ood_utility_*`, `synthetic_selective_risk_*`, `diabetes_covariate_shift_*`; Figures 1-3 and 8. |
| 5. Baseline fairness | Conformal baseline changed both the point predictor and interval method. | Added split conformal intervals around the same Standard ANN point predictor and retained conformalized quantile boosting as a distinct non-neural baseline. Restored the single-head MSE-dropout ablation. | `fit_conformal_ann`, `fit_cqr`, `MSE Dropout p=0.1` in `synthetic_fixed_summary.csv`. |
| 6. Code/reproducibility | Log-variance clipping mismatch, incorrect clipping gradient, and Protocol-B data regeneration bug. | Training and evaluation both use `[-6, 6]`; `torch.clamp` supplies zero derivative outside bounds; Protocol B generates each outer dataset once and reuses it for both inner seeds. Added executable unit tests for these points and exact mixture NLL. | `analysis/reviewer10_final_analysis.py`; `tests/test_reviewer10_analysis.py`; `results/pytest_log.txt` (5 passed). |
| 7. Dataset validity | Firm dependence and target ceiling were not handled. | Grunfeld is evaluated leave-one-firm-out and with disjoint temporal windows. California Housing was removed from primary evidence because a valid ceiling-exclusion/Tobit rerun was unavailable. This limitation is stated rather than concealed. | `grunfeld_group_*`, `grunfeld_temporal_*`; Limitations Section 4.8. |
| 8. Interpretation | Conclusions overstated generality and causal explanations. | Rewrote claims as benchmark-specific. The controlled multicollinearity ablation did not show a monotone VIF-width relation, so the earlier causal explanation was rejected. OOD detection is separated from error ranking. | `sbpr_multicollinearity_summary.csv`; Discussion Sections 4.3-4.5. |
| 9. Writing/organization | Main text was overloaded and references needed audit. | Removed CQRI, consolidated core findings, moved full diagnostic outputs to the reproducibility archive, and standardized references. The revised paper uses a direct research-question structure and explicit limitations. | Final manuscript; `results/` archive; references. |
| 10. Equations/figures/layout | Equations were blank/rasterized, appendix text was small, and uncertainty labels were inconsistent. | Rebuilt all equations as native editable text using Cambria Math, regenerated 300-dpi figures, defined whether error bars are SD, added raw auditable CSVs, and performed full-page DOCX/PDF visual QA. | Final manuscript and archived figures. |
